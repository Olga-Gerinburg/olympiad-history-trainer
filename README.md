# 🏛️ Олімпіадний тренажер з історії

Інтерактивний веб-додаток для підготовки учнів (6–11 класи) до олімпіад, НМТ/ЗНО та самостійного вивчення історії України і всесвітньої історії. Проєкт побудований на концепції мікронавчання: система генерує унікальні уроки по 20 запитань із загальної бази.

## ✨ Головні можливості (Features)

* **Безкінечна генерація мікроуроків:** розумний алгоритм тасує питання, пріоритетно видаючи нові, та підмішує вже пройдені для закріплення матеріалу.
* **Різноманітні формати завдань:**
  * Вибір однієї або кількох правильних відповідей.
  * Встановлення хронологічної послідовності (drag-and-drop інтерфейс).
  * Логічні пари (встановлення відповідності).
  * Короткі текстові відповіді з "розумною" перевіркою (система ігнорує регістр, зайві пробіли та розділові знаки).
  * Картки для самоперевірки (Flashcards).
* **Динамічна база через Google Sheets:** усі завдання, ключі та пояснення підтягуються з Google Таблиць у реальному часі за допомогою `PapaParse`. Додавання нових завдань не потребує втручання в код.
* **Збереження прогресу:** локальне сховище браузера (`localStorage`) запам'ятовує набрані бали, номер мікроуроку та пул пройдених питань для кожного класу окремо.
* **Адаптивний UI/UX:** сучасний інтерфейс на базі Tailwind CSS, що ідеально працює як на комп'ютерах, так і на мобільних пристроях. Вбудований лайтбокс для детального перегляду історичних карт та портретів.
* **Інтеграція ШІ:** можливість генерувати детальні пояснення до складних завдань в один клік.

## 🛠 Технологічний стек
* **Frontend:** HTML5, JavaScript (ES6+), CSS3
* **Стилізація:** Tailwind CSS
* **Парсинг даних:** PapaParse (для зв'язку з Google Таблицями)
* **Іконки:** Font Awesome
* **Хостинг:** GitHub Pages
